# Personal Portfolio

Live site: https://onjamm.github.io/PersonalPortfolio/

A personal portfolio built from scratch with plain HTML and CSS — no frameworks, no libraries, just hand-crafted markup and styling. Designed with accessibility, responsive design, and clean UI/UX as core priorities.

## What's inside

- **Home** — intro and a breakdown of my values as a developer
- **Projects** — a look at things I've built
- **Resources** — languages and tools I work with
- **Resume** — downloadable PDF resume

## Philosophy

I care about building things that anybody, on any device, can engage with and enjoy. That means accessible markup, responsive layouts, and interfaces that don't get in the way of the user.
